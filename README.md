Olist Customer Analytics

Customer analytics project using PostgreSQL and Power BI to analyze customer spending, customer segments, retention, and geographic performance.

Tools

- PostgreSQL
- Power BI
- Power Query
- DAX

Project Work

- Designed customer, product, and location dimensions with order and order-item fact tables using SQL.
- Cleaned customer and location data and handled missing and unmatched records.
- Created surrogate keys for reporting and established relationships between reporting tables.
- Calculated customer lifetime spend, order dates, and cumulative spend for value-based customer segmentation.
- Built a Power BI dashboard covering customer spend, orders, active customers, AOV, repeat rate, segmentation, and geographic performance.
